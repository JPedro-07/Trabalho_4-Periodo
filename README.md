# 🤝 Doe Já — Sistema de Doações

## 📌 Sobre o projeto

O **Doe Já** é um sistema que conecta **instituições que precisam de doações** a **pessoas interessadas em ajudar**.

A plataforma organiza as necessidades das instituições por prioridade, facilitando o processo de doação.

## 🎯 Objetivo

Tornar as doações mais **organizadas, acessíveis e transparentes**, aproximando doadores e instituições.

## 👥 Perfis de Usuário

- 👤 **Doador:** visualiza necessidades e realiza doações.
- 🏢 **Instituição:** cadastra necessidades e prioridades.
- 🛠️ **Administrador:** gerencia e acompanha as doações.
